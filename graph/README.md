# Public research graph

This directory contains the first source-receipted graph for *The Return of Magic: Causal Compression in Adaptive Systems*.

## Files

- `schema-v1.json` — node types, edge relations, status dimensions, and integrity rules.
- `graph-v1.json` — curated graph snapshot generated 2026-09-11.
- `AUDIT.md` — current inventory, evidence audit, unresolved mismatches, and next gates.

## Boundary

This is a public research graph, not an AxiomReason profile export. AxiomReason profile holdings are a commitment/derivation projection. The graph additionally contains definitions, descriptive Statements, bounded experiments, hypotheses, receipts, and unresolved questions.

The graph does not infer support from topical similarity. An experiment document is not connected to a paper hypothesis by `supports` or `tests` until the comparator, scope, and claim contract have been reviewed.

## Integrity

The snapshot has passed focused ad-hoc verification:

- JSON parses;
- node IDs are unique;
- edge IDs are unique;
- all edge endpoints resolve;
- every node has a source reference.

This verifies graph integrity only. It does not verify the truth of claims, semantic correctness of every edge, browser rendering, or AxiomReason profile projection.
